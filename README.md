# Museo Virtual de San Patricio del Chañar

Primera base funcional del Museo Virtual de San Patricio del Chañar.

## Principios

- Territorio, memoria, personas, patrimonio y futuro.
- El museo no inventa hechos históricos.
- Contenido, interfaz y motor deben permanecer separados.
- Mobile-first y compatible con GitHub Pages.
- Las piezas se incorporarán progresivamente.
- La memoria comunitaria pasa por recibir → revisar → contextualizar → curar → publicar.

## Tecnología

HTML + CSS + JavaScript, sin backend obligatorio.
