# Modelo curatorial y documental — PL1+

Este documento define cómo crecer sin contaminar el fondo.

## 1. Jerarquía

`Registro` = unidad documental principal.  
`Pieza` = forma de presentación de un registro.  
`Fuente` = evidencia/procedencia utilizada para sostenerlo.  
`Relación` = vínculo explícito entre registros.  
`Colección` = agrupación temática de registros.  
`Multimedia` = objeto digital asociado a uno o más registros.  
`Pregunta` = investigación abierta que todavía no debe resolverse por imaginación.

## 2. Estados documentales

Los estados no son adornos. Determinan cómo puede comunicarse una pieza:

- `EVIDENCIA_LOCAL`
- `CONTEXTO_REGIONAL`
- `FUENTE_HISTORICA`
- `FUENTE_INSTITUCIONAL`
- `MEMORIA_ORAL`
- `EN_INVESTIGACION`

Una memoria oral puede ser valiosa sin convertirse automáticamente en prueba de un hecho. Una fuente institucional puede documentar una versión institucional sin cerrar por sí sola una investigación histórica.

## 3. Proveniencia mínima para nuevos objetos

Antes de incorporar una fotografía, documento, audio o video deben registrarse, cuando corresponda:

- identificador estable;
- título;
- fecha o rango de fecha, o indicación explícita de desconocimiento;
- creador/autor si se conoce;
- procedencia;
- fuente o custodio;
- relación con el territorio;
- registro o registros vinculados;
- derechos/condición de uso;
- descripción;
- estado de verificación;
- restricciones sensibles si existen.

## 4. Regla de fotografía

Una fotografía no entra porque “queda linda”.

Debe poder responder:

**¿Qué vemos? ¿Quién la aportó? ¿Cuándo? ¿Dónde? ¿Quién la creó? ¿Podemos publicarla? ¿Qué registro documental sostiene su incorporación?**

Si faltan respuestas críticas, el objeto puede permanecer como **búsqueda abierta**, no como pieza exhibida.

## 5. Regla de testimonios

Para nuevos testimonios se recomienda conservar dos capas:

1. **voz de la persona** — lo que declara;
2. **contexto documental** — qué otras fuentes permiten contrastar, contextualizar o dejar abierta esa declaración.

La interfaz debe mantener visible esa diferencia.

## 6. Regla territorial

Cada afirmación debe poder clasificarse como:

- específicamente local;
- regional/contextual;
- fuente histórica;
- institucional;
- memoria;
- investigación pendiente.

No se permite borrar esa distinción para hacer una narrativa más cómoda.

## 7. Regla de crecimiento

La profundidad debe aumentar en:

**fuentes → piezas → relaciones → preguntas → interpretación → educación**

y no simplemente en:

**más menús → más páginas → más botones → más efectos**.
